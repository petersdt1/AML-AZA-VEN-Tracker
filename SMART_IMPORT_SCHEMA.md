# Smart Import endpoint contract

POST JSON to the configured endpoint:

```json
{
  "schema_version": "aml_bmbx_extract_v1",
  "source_type": "auto",
  "marrow_date": "01/25/2024",
  "diagnostic": true,
  "source_text": "...",
  "instructions": "observation-only extraction instructions"
}
```

Return either the extraction object directly or wrapped in `data` or `extraction`.

Core rules:
1. Return observations only. Never calculate ELN, response, complex karyotype, AML-MR, or eligibility.
2. Unknown/null when the source does not establish a field.
3. Never infer Negative from absence.
4. Preserve Positive versus Negative for FISH/rearrangements.
5. RUNX1 copy gain is not RUNX1::RUNX1T1.
6. `tested_genes` is for explicit sequence-level gene-panel coverage only. Generic FLT3 coverage does not establish FLT3-ITD/TKD negativity; generic KMT2A sequence coverage does not establish rearrangement negativity.
7. Explicit FLT3-ITD/TKD results should be returned as `FLT3-ITD` / `FLT3-TKD` Positive or Negative observations. Explicit KMT2A rearrangement outside FISH/cytogenetics should be returned as `KMT2A-REARRANGEMENT`.
8. Include short source evidence snippets for extracted findings.

The full schema/instructions are generated by `smartExtractionPrompt()` in `index.html`.
